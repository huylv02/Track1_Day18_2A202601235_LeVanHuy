Tối ưu Sentiment Prompt
Mục tiêu: Viết System Prompt để mô hình phân loại ý kiến khách hàng thành 3 nhãn: POSITIVE, NEGATIVE, NEUTRAL.

Yêu cầu định dạng: Kết quả trả về BẮT BUỘC phải là đối tượng JSON thô (không bọc trong markdown codeblock): 

{
  "sentiment": "POSITIVE",
  "confidence": 0.95,
  "reason": "..."
}
  • Phân tích kết quả kiểm thử ở Tab 2 để tối ưu hóa.
  • Học viên hiện đang loay hoay với lỗi JSON Parsing do prompt chưa định dạng đúng.
Kịch bản thử nghiệm Option A: Hãy nhấn nút Chạy thử nghiệm để mô phỏng hành vi loay hoay lỗi. Sau lần chạy thử thứ 4 liên tiếp bị lỗi, hệ thống AI Radar phòng Lab sẽ tự động kích hoạt đề xuất hỗ trợ từ Trợ giảng.
Kịch bản thử nghiệm Option B: Nếu gặp lỗi bế tắc không thể tự sửa, hãy chủ động nhấn nút đỏ GỬI YÊU CẦU SOS ở phía trên để yêu cầu trợ giúp ẩn danh từ Trợ giảng.
Kịch bản thử nghiệm Option C: Hãy nhấn nút Chạy thử nghiệm. AI Co-pilot sẽ phát hiện Prompt thiếu định dạng và hiển thị cảnh báo, đưa ra gợi ý sửa lỗi trực tiếp tại chỗ.
